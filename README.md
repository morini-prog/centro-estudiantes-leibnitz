# Centro de Estudiantes — Instituto Leibnitz (Villa María)

Página web informativa institucional sobre el marco normativo, la organización y las funciones de los centros de estudiantes del nivel superior en la provincia de Córdoba.

## Estructura del proyecto

- `index.html`: Documento semántico HTML5 con navegación interna, secciones normativas, esquema relacional de órganos, funciones, responsabilidades, guía orientativa, acordeón accesible de preguntas frecuentes y documentos oficiales de consulta.
- `styles.css`: Sistema de diseño institucional (azul principal, acentos naranjas moderados, fondos blancos y gris muy claro, tipografía Open Sans y diseño adaptable a celulares, tablets y computadoras).
- `script.js`: Interactividad accesible por teclado (menú móvil, seguimiento de sección activa y acordeón WAI-ARIA).

## Previsualización

Podés abrir `index.html` directamente en cualquier navegador o iniciar un servidor local:

```bash
python3 -m http.server 8080
```
